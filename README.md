# Expense-Tracker

A simple and responsive expense tracker built using HTML, CSS, and JavaScript.

## Features
- Add income and expense transactions
- Category-wise transaction tracking
- Automatic balance calculation
- Persistent data using localStorage
- Filter transactions by category
- Responsive UI for mobile and desktop

## Technologies Used
- HTML
- CSS
- JavaScript (Vanilla JS)
- Browser localStorage

## How It Works
- Transactions are stored as objects in an array
- Data is saved and retrieved from localStorage
- Balance, income, and expense are calculated dynamically
- UI updates automatically on add/delete actions

## Future Improvements
- Edit transactions
- Monthly summary
- Charts for expense analysis
